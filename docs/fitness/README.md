# Vessel Gym Workout Plan (80 kg ? 72 kg)

Personalized 4-day training plan for ship gym equipment, with YouTube form videos.

## Files

- `Vessel_Gym_Workout_Plan_80_to_72kg.xlsx` — open in Excel **or** Google Sheets
- `create_workout_sheet.py` — regenerates the workbook

## Open in Google Sheets

1. Upload `Vessel_Gym_Workout_Plan_80_to_72kg.xlsx` to [Google Drive](https://drive.google.com)
2. Right-click the file ? **Open with** ? **Google Sheets**
3. (Optional) **File ? Save as Google Sheets** so it becomes a native Sheet
4. Tap any **Watch form video** cell to open the YouTube demo
